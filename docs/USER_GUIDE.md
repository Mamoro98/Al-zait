# 📱 Al Zait User Guide - Interactive News Assistant

## Welcome to Al Zait! 🤖

Al Zait is your intelligent Arabic news assistant for Sudan news. You can chat with the bot directly to get answers about current events, request audio summaries, and stay informed 24/7.

---

## 🚀 **Getting Started**

### Starting a Conversation
1. **Find the Bot**: Search for `@AlZaitNewsBot` on Telegram (or use your custom bot)
2. **Start Chatting**: Send `/start` to begin
3. **Ask Questions**: Type your questions in Arabic or English
4. **Get Answers**: Receive intelligent responses with sources

### First Steps
```
/start → Welcome message and introduction
/help → Complete guide and available commands  
"ما آخر الأخبار؟" → Ask your first question!
```

---

## 💬 **How to Ask Questions**

### Good Question Examples

**Arabic Questions:**
- `ما آخر التطورات السياسية في السودان؟`
- `كيف هو الوضع الاقتصادي الحالي؟`
- `أخبرني عن الوضع الأمني في دارفور`
- `ما هي آخر أخبار الخرطوم؟`
- `كيف هو وضع الزراعة في البلاد؟`

**English Questions:**
- `What's the latest political situation in Sudan?`
- `Tell me about the economic developments`
- `How is the security situation in Darfur?`
- `What are the recent news from Khartoum?`
- `Are there any new development projects?`

### Tips for Best Results
✅ **Be Specific**: Ask about particular topics or regions  
✅ **Use Keywords**: Include terms like "politics", "economy", "security"  
✅ **Be Clear**: Write complete questions rather than single words  
✅ **Try Both Languages**: The bot understands Arabic and English  

❌ **Avoid**: Very vague questions like "what's new?"  
❌ **Avoid**: Single-word queries without context

## 🎛️ **Available Commands**

### Basic Commands
| Command | What it Does | Example |
|---------|-------------|---------|
| `/start` | Welcome message and bot introduction | Always start here! |
| `/help` | Complete usage guide and tips | When you need assistance |
| `/stats` | System statistics and database info | See how much content is available |
| `/latest` | Most recent daily news digest | Get the morning summary |
| `/audio` | Convert your last answer to speech | Perfect for listening while busy |
| `/clear` | Clear your conversation history | Start fresh |

### How to Use Commands
Simply type the command (starting with `/`) and press send:

```
User: /stats
Bot: 📊 إحصائيات الخبير الإخباري
     📰 إجمالي المقالات: 150
     🌍 اللغات المتاحة: العربية، الإنجليزية
     📡 المصادر الرئيسية: 8
```

## 🎙️ **Audio Features**

### Getting Audio Responses
1. **Ask a Question**: Type your question normally
2. **Get Text Answer**: Receive the written response  
3. **Request Audio**: Type `/audio` to get speech version
4. **Listen**: Download and play the MP3 file

### When Audio is Automatically Offered
The bot will suggest audio versions when:
- Your answer is longer than 100 characters
- The confidence level is above 50%
- The response contains substantial information

### Audio Features
🎙️ **Professional Arabic Voice**: Clear, natural pronunciation  
🎵 **Intro/Outro**: Branded segments with Al Zait signature  
⏱️ **Optimized Length**: Perfect for listening while commuting  
📱 **Direct Download**: Sent as Telegram audio file

## 📊 **Understanding Bot Responses**

### Response Structure
Every answer includes:

1. **Main Answer**: The core information in Arabic
2. **Sources**: Where the information came from
3. **Confidence Level**: How reliable the answer is  
4. **Al Zait Signature**: Bot identification

### Confidence Levels
🟢 **High (80-100%)**: Very reliable, multiple strong sources  
🟡 **Medium (50-79%)**: Good information, decent sources  
🔴 **Low (0-49%)**: Limited information, use with caution  

### Source Information  
- **Article Titles**: Headlines from original news
- **Publication Names**: News outlets and agencies
- **Publication Dates**: When the news was published
- **Direct Links**: URLs to original articles (when available)

## 🆘 **Troubleshooting**

### Common Issues & Solutions

**Bot Doesn't Respond**
- Check your internet connection
- Try typing `/start` to wake up the bot
- Wait 30 seconds, then try again

**Getting "No Information" Responses**
- Try more specific questions
- Use different keywords
- Ask about more recent topics
- Check `/stats` to see available content

**Audio Not Working**
- Ensure you asked a question first
- Try `/audio` immediately after getting an answer  
- Check if the previous answer was substantial enough

**Conversation Seems Confused**
- Use `/clear` to reset conversation history
- Start with a fresh, clear question
- Avoid very long or complex multi-part questions

### Getting Help
1. **Type `/help`**: Complete usage guide
2. **Ask Simple Questions**: Test with basic queries
3. **Check `/stats`**: Verify system is working
4. **Try `/latest`**: See if news data is available
